# Bakahent - Anime Streaming Website

[![Bakahent Logo](https://img.shields.io/badge/Bakahent-Anime--watching--platform-blue.svg)](https://github.com/Kishmat/bakahent.git)

## Introduction
Welcome to **Bakahent**, an anime streaming website built using **HTML**, **CSS**, **PHP**, and **JavaScript**. Bakahent is designed to provide a smooth and enjoyable experience for anime enthusiasts. It allows users to stream anime, keep track of the episodes they've watched, and provides a seamless interface for discovering and enjoying the best of anime. With features such as a beautiful UI, personalized recommendations, and an admin panel for easy content management, Bakahent is your one-stop platform for all things anime.

This project is hosted on GitHub, and you can access the repository here:  
[https://github.com/Kishmat/bakahent.git](https://github.com/Kishmat/bakahent.git)

---

## Features

✨ **Key Features of Bakahent**:

1. **Track Your Progress:**
   - The website remembers the last episode you watched and shows a popup asking if you'd like to continue where you left off when revisiting the site.

2. **Admin Control:**
   - Admins have the ability to add new anime titles into various sections, such as **Trending** (displayed on the homepage with a slider), **Anime Lists**, **Seasons**, and **Episodes**.

3. **Beautiful User Interface:**
   - A clean, responsive, and modern UI that provides an immersive anime-watching experience. The layout is simple yet stylish for an optimal browsing experience.

4. **Login System:**
   - Users can create accounts and log in to manage their preferences and watch history. Personalize your anime experience!

5. **Powerful Search:**
   - Easily search for anime by **English name** or **Japanese name**. No need to worry about remembering the exact title!

6. **Responsive Video Player:**
   - Enjoy watching anime on any device with a fully responsive video player that adapts to both mobile and desktop screens.

7. **Age Verification for Adult Content:**
   - Bakahent includes an age-verification system for adult content, ensuring that only users of the appropriate age can access such content.

8. **Detailed Anime Information:**
   - Access important details about each anime including its **status**, **studio**, **theme**, **seasons**, and more.
